# 九级 3.0 · 共生远征

本次实现基于 2.0.0，保留六地与九级主线。开发分支 codex/jiuji-3.0-coexist；TapTap 已授权的 1.3.2 → 2.0 审核流程及不可变包体保持独立。

## 交付范围

- 存档 v9：兼容 v2–v8，迁移前保留原档，三个恢复点，损坏与配额失败不破坏可用进度。
- 手机控制设置、材料来源追踪、相邻交互选择、横竖屏与安全区；后台暂停。
- 潮汐群岛、地心菌窟两类可重复裂隙，每类三个路线模板；固定种子、风险、事件、奖励；保存中途进度、主动撤退与营地结算。
- 18 个有真实代价与后果的远征事件、分层提示与无扣料错误尝试；八种普通生物、两名可战斗或修复的守卫。
- 四名伙伴的招募、随行、营地岗位、故事；真实消耗、库存上限、停止条件，不离线生产。
- 12 个装备模块，探索/工程/共生配置，可在营地更换；六项功能设施、八项收藏装饰。
- 九级成长引导、生态修复项目、八级多营地协作、九级终局远征。
- 角色动作、装备/伙伴/虫洞反馈；低动态选项、分享种子与暂停拍照。

## 验收顺序

1. 规则与存档测试，特别是重复领奖、材料守恒、满仓、取消动作、退出重进。
2. 现有所有旅程回归，新增正常资源闭环旅程。
3. Ego Lite 本地桌面与手机横竖屏交互、截图、控制台检查。
4. 3.0 独立候选包验收。浏览器尺寸模拟与真机结果分别记录。

多人、账号云存档和微信小游戏适配后续独立验证，不作为本次已实现功能宣传。

## 2026-11-09 粉丝建议补充

采纳“硬核生存逐步走向文明”的方向，加入三个原创聚落（河湾、石脊、星苇）、当地 NPC、人口与公共储备、好感、每日有限以物易物、一次性物资委托，以及六项可选协作研究。聚落分支不加入九级主线的硬门槛，旧档可继续成长。

据点先采用三格回合制小型战术事件：观察预警、移动、出手、格挡；先免费演练，再选择消耗补给的正式事件。每地据点只领奖一次，并保留同奖的和平修复方式。大地图即时多单位指挥、征服领地和复杂外交暂不纳入这次版本，避免稀释采集、营地和共生远征。

新手从三幕可跳过的岸边情景开始，逐步提示石斧、营火和第一夜。手机首期保留三个基础动作键；成长提示常驻且可随时展开全部系统。死亡按当时的饥饿、光照、淋雨、温度和生态状态给出准备建议；探索模式一级前三天提供一次保留全部物资的守岸人救援，后续仍遵循原有探索/求生规则。

科技前置和短缺资源直接写明，完整前置图检查无循环；二级之后的成长提示直接读取实际文明主线条件，避免把经典旅程的条件显示给星海主线玩家。
