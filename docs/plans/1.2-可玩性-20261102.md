# 《九级》下一阶段：让每次远征都有值得带回家的东西

2026-11-02。依据已核实的公众号反馈与现有 1.1 代码制定；下文是设计与验收计划，不是已上线功能。

## 1.2 实施进度

已实现播种与成长修复、九项委托与十八处探索点、晾晒架/育苗床与三类作物/四种补给、附近箱子供料、弓锤专长与诱饵、领地/狼群警戒、探索模式重生与遗落包。P1 的远征归营循环已由无击杀区域野怪的正常操作流程验证。

主动营地守护挑战、四级以上新增经营系统、联机和微信版本仍是后续里程碑；不作为本次 1.2 的已实现功能宣传。

## 先解决的体验

读者首先卡在「我接下来能做什么、材料从哪里来、科技为什么不能点」。本轮 1.1.1 先补播种、共鸣、生态与研究条件的可操作引导。下一版本以已有四片荒野为基础，完成「准备补给 → 选择目的地 → 处理遭遇 → 带回材料 → 改造营地 → 再出发」循环。

目标是新玩家知道第一晚做什么，熟悉游戏后每次出门需要为武器、食物和携带空间做选择；返营能够获得新的用途。单纯增大空地图或提高敌人血量，无法解决这一目标。

## 开发顺序

| 优先级 | 内容 | 玩家实际获得什么 | 验收边界 |
| --- | --- | --- | --- |
| P0，本轮完成 | 1.1.1 成长引导与播种修复 | 不再把播种和造农圃混为一谈；能从卡住的位置找到行动入口 | 新存档不注入物资，三次播种 → 冥想 → 共生实践成立，旧存档继续玩 |
| P1，1.2 首个可玩切片 | 远征委托 + 小型探索点 | 每次出门有一个明确目标，有选择和回报 | 完成一轮约 15–25 分钟的设计目标；需玩家实际体验再调时长 |
| P1，随后 | 营地储物取用、种植与料理选择 | 带回的材料改变日常生存，农场与远征相互支撑 | 箱子、设施、配方材料守恒；跨图取用范围明确 |
| P2 | 野怪行为与装备专长 | 观察习性、选择路线和装备，而非只比数值 | 攻击有可见预警，近战/远程/避战都存在可行路径 |
| P2 | 死亡恢复与难度选项 | 初次失败后有继续学习的机会 | 旧存档迁移、死亡与取回流程不刷物资、不覆盖唯一备份 |
| P3 | 四级以后的阶段差异 | 晋升改变玩法和管理范围 | 每两级至少引入一种新操作或决策，避免只换名字涨数值 |
| 单独里程碑 | 双人合作、微信小游戏/小程序 | 共同营地与更方便的移动入口 | 先做独立技术验证，不作为 1.2 阻塞项或已支持功能宣传 |

## 1.2 先做这一轮：林海回声

只选苔痕林海做完整样板，验证好玩之后再推广到另外两张远征地图。

1. 营地出现三项可选委托，任选一项追踪：修复古井、寻回种荚、观测野怪巢穴。完成后才刷新下一组，不做现实时间每日签到。
2. 每张地图布置六处固定种子生成的小型探索点。首个样板包含受损古井、蛛丝林穴、倒伏巨木。地图记录已经访问和已经领取的状态，重复往返、读档不刷新奖励。
3. 古井有两种处理方式：投入铜锭快速修复，或投入种子、食物并在当地观察更久。奖励为同一类营地升级部件，但有不同的材料、时间与风险代价，保留避战路线。
4. 返回营地可以二选一升级：晾晒架制作适合远征的口粮，或育苗床提高种子与生态补给。暂不同时送齐全部升级，需要下一次远征补足另一条路线。
5. 第一项委托的奖励会解锁第二项用途，例如林海种荚可培育抗寒作物，为霜月冻土准备。玩家下一趟出门的理由来自已见到的新配方。

最小范围：三项委托、三种探索点、一种新材料、两项营地升级、一项新料理。先把这一个循环做透，再增加数量。

## 营地经营的取舍

- 存在附近储物箱中的普通材料可用于制作，界面分别展示背包与箱内数量。只取当前地图、指定半径内材料，先背包后箱子；装备不被误当材料消耗。离开半径后按钮及时更新，读档与拆箱不会复制物品。
- 加入三类作物：快熟但饱食少的块根、适合旅行的耐寒谷物、用于冥想的荧光花。种植与农圃分工清楚：青杉补植修生态，农圃种作物供生活。作物有季节偏好，冬季仍保留钓鱼、储粮等生存方案。
- 料理先做保暖、远行、恢复三类功能。食物选项决定出门路线，不堆十种只有不同图标的饱食数值。
- 营地扩展采用少量功能设施；家具与装饰可随后共建。先保证每个建筑有可观察的用途。

## 野怪、装备与失败

- 野猪守食、蜘蛛守巢、霜狼结伴巡逻。威胁范围可观察；允许绕行、诱饵分散或战斗获取资源。守卫保留独特招式和一次性里程碑奖励。
- 初期每类武器只增加两种专长选择，例如弓的稳准射击/连射、锤的打断/破甲。保留耐久与耗材成本，不把高级武器做成所有场景都最优。
- 可选「营地守护」作为玩家主动启动的挑战，提前告知准备时间和奖励。基础主线不强制触发袭击，避免建好家之后被无提示摧毁。
- 新存档可选择求生/探索难度。探索模式死亡后回到最近营地，远征战利品留在可回收背包；求生模式保留更高风险。需要防止复制物品，且不把墓碑放在海中或不可达区域。

## 让九级成长真正改变玩法

- 1–2 级：手作营地、食物与第一晚；补种、冥想、研究形成双轨成长。
- 3–4 级：远征路线、临时营地与折跃网络；探索知识决定旅行效率。
- 5–6 级：生产与生态网络，逐步减少手动补料；意念显化改变材料瓶颈，同时保留能量/共鸣取舍。
- 7–8 级：跨图守护委托与文明选择，解决生态和居民的不同需求。任务可通过援助、沟通、建设完成。
- 9 级：留下建设或完成结局；留存世界可继续挑战探索与守护目标，给已经飞升的营地一个持续用途。

这些是后续方向，先完成林海样板，避免一次展开全部系统。

## 合作与微信版本

先验证双人共同营地：服务端保存权威状态，明确物资所有权、建造冲突、暂停、掉线重连和存档恢复，再扩大人数。现有纯本地规则不能靠共享 localStorage 变成多人游戏。继续使用独立服务与数据，保护同机《大国崛起》。

微信版本先抽离文件存档、图片/音频加载和触摸输入适配。先验证真机首屏、后台恢复、存档导入导出与内存，再决定小游戏和小程序各自承载什么；不把网页浏览器模拟当作 iPhone 或微信真机验收。

## 如何判断更好玩

- 新玩家能不看外部攻略完成播种三次、取得第一次共鸣并过第一晚；卡点记录用于调整游戏内提示。
- 同一份样板委托至少有两种材料/时间/风险不同的可行方案，保留非战斗推进。
- 一次远征带来的材料能在返营后立即解锁可见的新用途；做完之后有下一趟明确目标。
- 验证普通采集、无战斗路线与选择战斗路线，不通过注入资源跳过瓶颈。
- 单元测试覆盖奖励防重复、材料守恒、跨图存档和失败恢复，实际浏览器检查 320/390/桌面，另安排 iPhone Safari 与微信目标环境真机体验。
- 若未来增加阶段转化统计，先定义字段并沿用自愿同意；本轮不扩大统计范围。上面均是验收目标，没有冒充已测得的留存率或用户数据。
