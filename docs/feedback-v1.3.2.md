# 九级 1.3.2：TapTap 玩家反馈修复

## 反馈来源

- [进入时闪烁、无法游玩](https://www.taptap.cn/moment/867400190217159679?group_id=1633502)。原帖截图停留在 TapTap 启动画面，未提供设备型号，不能单凭图片确定全部设备故障原因。
- [手机操作界面异常](https://www.taptap.cn/moment/867552092372337852?group_id=1633502)。原图底部方向键、快捷栏、动作键遭裁切。

## 修复

- 移除游戏容器 420/400 像素最低高度，按宿主真实可用高度布局；兼容不支持动态视口单位的内置浏览器。
- 整理横屏布局，方向键、快捷栏和动作按钮分别留出空间；320 像素矮竖屏改为横排菜单，避免遮挡触控按钮。
- 修复匿名统计默认关闭时仍调用 `crypto.randomUUID()` 的启动故障；缺少此接口或整个 `crypto` 对象时可继续游戏。
- 在普通入口与离线包里补齐 `Object.hasOwn`、数组 `at` 兼容处理；音频被宿主禁用时不阻断交互。
- 手机地形缓存从 3600×2800 降至 1800×1400，像素内存降为四分之一；逻辑地图与点击坐标不变。换图先释放旧缓存，主画布像素倍率限制为 1.5。
- 首帧绘制成功后隐藏加载层；脚本故障或加载过慢时显示重试提示，不自动刷新、不清除存档。
- 新增 `npm run package:taptap`：单游戏文件夹、经典单脚本、离线资源、默认不上报统计的可重复构建；与网页版共用修复后的样式和规则。

## 验证

- 90 项自动测试通过，其中 6 项覆盖旧接口、视口高度、启动故障提示、音频禁用与地形缓存释放。
- 正常资源路径九级旅程、营地与高阶生产旅程、钓鱼和四季生活旅程通过。
- 实际 ZIP 解包后在 Chrome 中走通采集树枝与燧石、合成石斧、刷新继续读档；未见脚本报错。
- 720×324、844×390、667×375、568×320、390×844、320×568 六种尺寸，菜单、触控按钮、八格快捷栏均未越界；菜单与触控按钮中心未被遮挡。
- 完成后恢复了测试用浏览器尺寸。

以上是自动化与桌面 Chrome 模拟视口验收，不等于 TapTap 客户端真机通过。仍需反馈玩家或真机复测确认原始闪烁问题是否全部消失。发行包最低编译目标为 Chrome 80 / Safari 14.1，不能据此承诺所有旧手机兼容。
