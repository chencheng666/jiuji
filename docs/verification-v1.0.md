# 《九级》1.0.0 本地验收

日期：2026-10-28。范围为单人、单岛屿浏览器游戏；联机、微信小游戏/小程序仍未实现。本记录不代表腾讯云或 GitHub Pages 已更新。

## 版本内容

新增四季、体感温度、钓竿、三处鱼塘、鱼汤、八项手册任务及一次性奖励、双份本地存档与损坏恢复。保留完整一级至九级主线与双结局。

资源与规则保持纯 JavaScript，无第三方运行依赖。新增 `seasons.js` 与 `storage.js`；鱼塘、溪鱼、钓竿使用原创 SVG。

## 自动验证

- `npm run check`：全部运行模块语法检查通过。
- `npm test`：38 项通过，含四季边界和旧存档迁移、冷热与保暖、钓鱼中断/耐久/恢复、鱼汤扣料/取货、奖励防重复、非法存档拒绝、主备恢复及存储容量异常。
- `npm run test:journey`：通过公开规则操作从一级抵达九级，完成六处遗迹和两个结局，无资源/科技/时间注入。
- `npm run test:wilderness`：3746 帧，完成采集、工具、营地、雨天、诱捕、披肩、炖煮，并真实钓鱼三次、制作并食用鱼汤、领取手册奖励。该脚本直接调用规则 API，不能等同人工全程浏览器游玩。

## 浏览器验证

本地 HTTP：`http://127.0.0.1:4321/?slot=v1-qa-20261028`，隔离验收存档。

- 欢迎页显示 1.0，手册正常打开、滚动和关闭。
- 通过原生导入按钮载入合法旅程检查点，手册读取钓鱼与鱼汤完成状态；点击工具奖励，浆果由 25 增至 29，按钮变为不可重复领取。
- 390×844 手册单栏、世界 HUD、方向键、采集与攻击按钮可见。
- 320×740 合成页文档宽度与窗口均为 320，无配方横向溢出；钓竿制作按钮存在。
- 营地画面有雨、鱼塘、涟漪与鱼群恢复倒计时。实际点击附近采集按钮等待钓鱼完成，溪鱼由 4 增至 6、钓鱼次数由 3 增至 4、钓竿耐久由 37 降至 36。
- 首次点中正在恢复的鱼塘时只移动未钓鱼；修正为直接提示剩余恢复秒数，避免误以为点击无效。
- 实际从菜单打开恢复确认并恢复上一份备份，出现成功提示；刷新后手册仍正常，页面图片无加载失败。
- 证据保存在忽略目录 `artifacts/v1-qa/`。移动端为桌面浏览器尺寸模拟，未宣称 iPhone Safari 真机验证。

## 边界

四季每季四天，属于轻量季节循环，尚无复杂季节生态链。库存容量沿用每种物品 9999；背包、营地、科技、选择均本地保存。没有云存档或联机同步。1.0 并不代表加入多星球或完整《饥荒》规模的内容。
