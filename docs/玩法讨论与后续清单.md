## 3.3 本轮补齐

1. **手机长按详情**：长按 0.5 秒查看资源、工具、恢复时间和建筑布局，短按仍走近交互。摇杆不触发详情；长按松手的兼容点击被拦截，不会误点弹出的按钮。
2. **资源地图记忆**：亲手采集过的资源留下足迹，区分采空与恢复；可追踪一个已发现目标，存档保留，不自动走位。每张常驻地图保留最近 160 处；临时裂隙不保留跨趟标记。
3. **三组建筑联动**：庇护区晾干、加工区晾晒、储物区取料。放置时预览，实际规则与预览一致，同类不叠加。手机先预览位置，再确认扣料。
4. **伙伴情境反应**：四人根据雨天、冬前、受伤、动物记录和两地共同事务说不同的话，不加“懒散扣效率”等随机负担。
5. **两地共同事务**：河湾真实付料打包，随身携带物资箱到石脊交付，再获得一次性回礼。两处聚落留下共建陈设；不添加远程共用库存。
6. **角色区分**：四职业重新绘制服装、帽形与道具，替换仅换色的兜帽 NPC。玩家左右侧身重画，统一比例、脚底基线和采集朝向，聚落内也使用方向素材。

## 3.4 本轮补齐

1. **高分屏性能**：SVG 精灵按尺寸缓存，有内存上限与失败回退；小地图使用预缩小地形；不变的生命与任务界面不反复重建。修正帧节拍、切后台停止绘制。
2. **画质与诊断**：均衡、清晰优先、流畅优先，只缩放场景画布。菜单按需查看真实绘制间隔与 CPU 耗时，可导出本地诊断，不主动上报。
3. **武器表现**：弓弦与箭迹、锤的挥击与落地环、霜矛突刺与冰痕，敌人显示打断和减速时间；不更改射程、伤害、命中时机。
4. **五课演练**：射程、打断、减速、诱饵绕行、冲锋侧移，复用正式规则，不消耗旅程物资。手机短横屏左右排列场景和按钮，触控目标至少 44 像素。

## 尚未开发或暂缓

| 优先顺序 | 功能 | 建议范围 |
| --- | --- | --- |
| 下一批 | 园丁机器人、搬运机器人 | 有真实种子、货物、电量、路径和仓储，先做两个型号；不变成凭空生产 |
| 随后 | 聚落主动求助与伙伴事件 | 先做可延期响应的生活事务，再评估紧迫事件；保护新手节奏 |
| 随后 | 小路和前哨站 | 规划碰撞、自动寻路、地图显示与手机建造后再加入 |
| 随后 | 终局编年史、旅程统计 | 记录成就与故事，不新增在线采集个人数据 |
| 待评估 | 潜行、投石引开、嗅觉与风向 | 需要与已有诱饵和敌人警戒统一设计，不能只加一个蹲姿按钮 |
| 待评估 | 食物保鲜、伤势与建筑维护 | 容易变成重复劳动或操作惩罚，暂不直接叠加三套消耗系统 |
| 待评估 | 部族外交、新游戏+ | 先明确对路线的真实影响与继承边界，再做；不把数值继承当重玩内容 |
| 暂不采用原案 | 固定 30% 丢货、强制选边、懒散减效率、骨折只能爬 | 先提供可读风险、回避手段与移动端容错，再讨论压力机制 |

这份清单是后续开发顺序，不是一次性全部加入当前版本的承诺。新增模块必须同时考虑旧存档、资源守恒、暂停/离线、移动端视野与操作。
