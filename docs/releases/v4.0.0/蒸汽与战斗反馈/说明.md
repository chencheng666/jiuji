# 4.0 蒸汽工坊与战斗反馈

本轮在 4.0「荒野共同体」的三类机器人、聚落事务、六地前哨基础上增加以下内容。

- 近战翻滚后 0.55 秒内攻击：沿翻滚方向安全突进最多 60 步，命中伤害为原来的两倍。正常扣耐久、晶能，弱点倍率照常计算；远程武器不触发，空挥也消耗连招机会，不刷新无敌和闪避冷却。手机沿用闪避和攻击两键。
- 野猪命中后安全击退最多 72 步，不穿入水域。夜影有苔影、棘影、羽影三种轮廓；靠近、绕行、锁定落点蓄势、突刺、后摇、畏光或负伤退去。
- 初级木鸡舍配陶碗、谷籽可见；自动喂料仍需后续科技、聚落任务和真实升级材料。
- 三级蒸汽传动需金属冶炼和共生实践。蒸汽工坊有锯切木板、铜锭、饲料三条生产线；本机仓储开工扣原料、每木材提供 24 秒工作热量，按产物 20 件目标停止新单。每批生态 −0.1，植树可恢复。
- 原料由玩家存入或搬运机送入，成品由玩家或搬运机领取。停机保留订单；切图、阅读面板、后台、离线均不补算。满仓等待，不吞产物；在制品/余热/库存/关联搬运任务均阻止拆除。
- 鸡舍、蒸汽工坊和夜怪由参数化 SVG 部件生成；主体缓存，运行时只画转轮、连杆与少量蒸汽。减少动态时停止活动部件，不更换现有 Canvas 2D 渲染器。

## 建议来源和取舍

已读取公众号《九级》3.4文章的相关留言及回复，粉丝分享了设施组件连接、传送带供料与自动合成的方向。当前检索到的近期私信没有对应的完整蒸汽机实现，也未获取粉丝源码。本轮独立实现蒸汽阶段和机器人接驳，不声称已经合入粉丝仓库。参考技术讨论仅采用程序化部件建模与缓存思想，未复制其他游戏代码或资产。

暂缓：默认火光外移动和耐久双重惩罚，以及野猪撞断树木。这些会改变探索成本与资源产出规则，先保留已有缺光预警、意识损耗和伤害，让新夜怪的战斗预警可读。未加入整套传送带编辑器，现有搬运机已可实现供料和出货。

本轮不更新 TapTap、uTools、统信审核包；网页生产和商店状态分别核对。原生安装包仍以官网标注版本为准。
