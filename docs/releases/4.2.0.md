# 九级 4.2.0 · 万木与夜影

- 十二种林木拥有独立树皮、冠形、分枝和近景叶片；灰皮桦、铁干橡、垂泪柳、赤鳞松、白骨杨、棘刺枣、血纹枫、石皮榆、雾冠杉、腐根槐、金叶银杏与黑檀木按区域稳定分布。
- 枫红、银杏金，松杉与黑檀常绿；落叶树冬季露出枝架。柳条分段风摆，杨桦叶背翻光；减少动态设置停止新增环境运动。
- 主干与冠层分别缓存，按距离和设备控制细节。同步树冠点击、屏幕裁剪、人物遮挡、悬停名称与长按详情。
- 旧档当前与离线地图补齐稳定树种；新树苗继承附近成熟树种。原有木材、种子、采集次数、工具损耗、生态与成长规则保留。
- 人物使用两段肘膝骨骼、交替抬步及采集/攻击姿态。五类夜影改为程序模型：影蝎油影与八肢、夜喙者碎玻璃与扫描线、金属野猪收刺与撞击、血蝠群聚散、蚀者流体与暗核。
- 沿用真实预警、命中、瞬移与吞火事件驱动外观；火炬、长明灯及心光保护规则保留。新增观察室仅展示模型，不写入玩家存档。
