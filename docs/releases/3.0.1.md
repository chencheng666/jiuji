# 九级 3.0.1 · 手机绘制与昼夜修复

对应 TapTap 玩家反馈：进入卡顿、画面爆闪、黑夜后停住。反馈来自 vivo Y200i、HONOR MTN-AN00X 及其他 Android 设备；未拿到这些手机做真机复测，不能把浏览器模拟当作同型号通过。

## 已修正

- 夜色缓冲的像素尺寸统一取整，小数 CSS 视口不再造成每帧反复分配画布；视野以外的光源跳过。
- 手机主画布限制在约 150 万像素；低内存设备进一步缩小地形缓存，主画布与夜色缓冲均只在实际像素尺寸变化时重新分配。
- 相同视口事件不重复广播重建；手机首次默认 30 帧，保留玩家主动选择 60 帧。
- 夜色画布分配失败时采用简化夜色，并明确提示；不修改黑暗伤害、光源与生存规则。
- 收到画布资源丢失事件时暂停世界、尽力保存，提供导出存档与重新加载；画布恢复后可继续。
- 手机传送去掉整屏闪光，保留虫洞与角色反馈。

## 验证与发行边界

规则测试新增小数视口连续 120 帧复用、分配失败降级、重复视口不清画布、高分屏预算、设备默认帧率等回归，总计 151 项通过。浏览器昼夜切换、触屏与画布恢复另按本次验收记录归档。

TapTap 1.3.2 离线修订已在线；当前更新草稿继承该包。3.0.1 将使用移除联网实现和外链的独立离线包，网页版、候选上传、正式提审和平台上线分别核验，不以本地修复代替客户端上线。
