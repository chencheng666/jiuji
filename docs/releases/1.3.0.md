# 九级 1.3 · 归途新生（当前修订 1.3.1）

2026-11-02。营地经营、远征选择与四级后的成长接续成一条旅程。

## 营地经营

- 新增经营总览入口，查看当前地图的设施、生产状态、远征回信和事件选择。
- 二级林地堆肥箱：3 种子、4 纤维，45 秒生产 2 堆肥；可安排一批或三批，一次投入整份订单。
- 堆肥可以照料土地，1 份恢复 4 生态；也可给生长中的育苗床追肥，每轮一次，剩余时间减少 40%。
- 育苗床与晾晒架改良后，下一轮耗时减少 20%；堆肥箱、共振工坊、循环织造台改良后，新订单耗时减少 25%。改良不改变已经投入的订单。
- 生产材料可取用当前地图 180 步内的箱子。生产只在所在地图活动时推进，暂停、后台、离线和跨图均不推进订单。

## 远征遭遇与回信

原有十八处探索点之外，三片远征地图各增加三段遭遇，共九段、十八种选择。地图以青绿色星标显示，经营总览可查看线索并前往当地事件。

幼林、旅人、种子库、冷却槽、采样队、旧信标、雪线营火、冰下苗圃和风雪回声，各有不同的物资和结果。部分路线即时获得回报，部分路线会在 60–90 秒有效游玩后带来回信。回信需要返回原岛手记台领取，满包时保留；事件和回信不会因往返、刷新而重复发奖。不要求击杀野怪，部分遭遇还有只记录环境的选项。

## 四级以后的生活

| 等级 | 新玩法 | 取舍 |
| --- | --- | --- |
| 四级 | 共振工坊凝结星露 | 荧光花、原晶和共鸣换取新的生产媒介；共鸣仍需留给晋升 |
| 五级 | 修缮古代构件 | 陨星碎片、铜锭和星露，换取有限探索奖励之外的构件来源 |
| 六级 | 循环织造台 | 消耗星露和共鸣，选择建材或林地补给，减少重复采集 |
| 七级起 | 远方守护台 | 先完成当地一段遭遇，再为对方提供两种援助方案之一；按当前地图活动时间完成，回赠需领取 |

守护援助保留对方选择生活方式的空间。回赠包含守护印记和物资，单一营地完成一轮后需等待 180 秒有效游玩才会再次接受援助；不强制发动营地袭击。
