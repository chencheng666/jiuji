# 3.0.0 · 共生远征

3.0 在原有采集、合成、四季生存、六地文明主线之上，加入「准备出发 → 观察与选择 → 带回成果 → 改变营地 → 再次远行」的循环。当前完成本地开发验收，构建包与正式上架分别记录。

## 开始玩

运行 `npm run dev`，新玩家从一级成长；旧版存档可以直接接续。暂停菜单或展开后的营地菜单中打开「共生远征」，到原岛营火 220 步内招募、装配、出发和领取邮袋。每次出发消耗 3 木材与 1 旅行口粮，返回免费。

| 等级 | 这一阶段的变化 |
| --- | --- |
| 一 · 初醒 | 采集、石器、营火、种植、四季与钓鱼；缺少材料时可追踪来源 |
| 二 · 协同 | 营地供能；可邀请植物学者苓与守火人烛，开始一次一人的随行 |
| 三 · 觉醒 | 潮汐群岛、回声扫描和武器模块；工程师铎与巡林者岚加入 |
| 四 · 远航 | 地心菌窟、通风观测、净化器、蓄水井；保留镜沙与折跃货运主线 |
| 五 · 同频 | 四个伙伴岗位使用真实物资协作，与原有自动装配、货运并存 |
| 六 · 塑能 | 原有晶能武器与三对投影臂可装配耗能、散热等模块 |
| 七 · 守序 | 完成两类裂隙观测，建造对应设施，交付物资修复水系与菌群 |
| 八 · 信使 | 在取得六地营地同意后，以工程或生态物资完成新一轮协作 |
| 九 · 归一 | 深层远征、共生碑与原有自由建造；保留守护和归源选择 |

新增内容按等级开放，不替换旧档的晋升规则，也不强制重新开局。

## 两类可重复远征

潮汐群岛有涨落潮周期：中线捷径涨潮后收窄，北侧高架路始终通行。地心菌窟的未修复区域会消耗生命与意识，植物学者随行可以减轻孢子伤害。两类地图各有三种路线布局；每趟种子决定布局、资源、天气和三段见闻。存档记录计时、阀门、事件选项及守卫状态，重新进入不会刷新奖励。

每张裂隙有三处观测点，通过碑文判断三条通路的开闭。提供三层提示，错误尝试不扣材料。净化器、蓄水井也能通过真实投入稳定所在观测区。两名守卫具有环形、冲锋、砸地或光束等阶段预警；修复三个观测点后，也可交付物资让守卫安定。

普通生物包括潜沙獾、鸣潮鹭、礁背龟、芦角鹿、孢甲虫、逐光蛾、根须伏兽与苔灯精。中立、警戒联动、逐光、护甲与不同攻击节奏需要分别应对。

十八段事件各有两个选项，明确展示材料、即时收益、生态变化与后续回信。选择仅生效一次。入口随时可返程；紧急救援保留食物、装备、图纸和纪念章，损失 30% 普通材料，回收袋模块降低至 15%。救援仍结算已完成成果。裂隙中的临时建筑会在返程后结束，永久营地继续建在六张常驻地图。

远征图纸和回信进入营地邮袋，背包满时保留待领取。记录保留最近 30 趟；同版本、同种子、同模式可以分享路线。

## 四名伙伴与营地工作

| 伙伴 | 随行作用 | 五级岗位 |
| --- | --- | --- |
| 苓 · 植物学者 | 孢子伤害减半 | 盐生育苗床，以芦果与种子育苗 |
| 铎 · 工程师 | 消耗燧石维修装备中的武器 | 维修桌，以燧石与树枝恢复工具耐久 |
| 岚 · 巡林者 | 降低普通生物警戒距离 | 哨亭，以浆果与纤维制作诱饵 |
| 烛 · 守火人 | 消耗浆果恢复生命 | 共用食堂，以菌菇与芦果制作行粮 |

每人有一段可交付物资完成的故事，最多一名伙伴随行。营地伙伴会走向岗位，夜间休息；输入不足或产物达到目标库存时停止开始新批次。工作需要玩家在原岛活动，打开面板、离开地图、后台与离线均不推进。四种岗位加净化器、蓄水井，共六种功能设施；八种收藏装饰使用纪念章制作。

## 模块与动作

十二种模块分别覆盖扫描、移动、救援回收、防潮、安抚、生态、伙伴辅助、伤害、射程、武器耗能、投影臂散热与作业耗能。探索装备、当前武器、投影臂各两个槽位，在原岛营火免费拆换，研发只付费一次。精准刻槽提高伤害同时增加攻击冷却，组合需要取舍；原有弓锤专长继续叠加。

补充左右朝向角色、采集抬手与挥动、钓鱼抛竿收线、建造和播种反馈、矿石裂纹、伙伴与设施反馈。保留原有三对投影臂的真实采集与能耗。暂停拍照可移动视野、缩放并导出带版本和种子的 PNG。

## 手机与存档

- 虚拟摇杆；采集、持续攻击、闪避和一个可选主动能力；左手布局、按键大小、透明度可设置。
- 竖屏操作键两排，横屏压缩标题、标签可横滑，营地菜单仍可收起。
- 30/60 帧上限、减少动态、天气粒子开关；实际帧率取决于设备。
- 材料追踪显示来源并可走向附近资源，相邻对象可选择交互目标。
- v9 自动兼容 v2—v8；保留旧存档槽、即时备份及三个时间恢复点。
- 损坏或写入失败的导入不替换当前进度；浏览器禁止存储时仍能开始并导出备份。

## 验收与发行

规则测试 129 项通过；语法检查通过。原有六组旅程回归通过，新「共生远征」旅程从本轮正式规则生成的九级存档接续，另以三级、四级角色各完成一次对应裂隙往返；九级旅程关闭自由建造，使用真实采集、合成、战斗、投入和步行，完成六趟远征、四名伙伴、十二种模块、六种设施、两项生态修复与六地协作。

Ego Lite 检查桌面及 375×667、390×844、667×375、844×390、568×320 等手机尺寸，检查摇杆、左右手、观测点、图片导出和受限存储。尺寸模拟不等于 iPhone、Android 或 TapTap 客户端真机验收；未将自动旅程时间当作玩家首通或留存数据。

构建使用独立的 `artifacts/taptap-v3.0.0/` 和 `releases/utools-v3.0.0/`。uTools ZIP 是源码工程备份，正式 UPXS 仍需开发者工具打包。Tauri 版本号同步，当前未构建和验收 3.0 统信 DEB。

初次开发验收阶段未部署腾讯云、未推送 GitHub、未提交商店审核；当前 TapTap 1.3.2 → 2.0 的既有审核安排及 2.0 候选包保持独立。多人联机、账号云存档、微信小游戏和小程序仍在后续范围。

可复现检查：`npm test`、`npm run check`、`npm run test:coexist`、`npm run package:taptap`、`npm run package:utools`。完整本地证据位于 `artifacts/jiuji-3.0/`，候选包最终摘要见各构建报告。两个包在浏览器中均通过新地图导入、触屏移动、十二种模块显示与无外部资源请求检查；uTools 宿主和 TapTap 真机仍待单独验证。
