# 九级 1.2.0 · 林海回声

从远征带回材料，用它改变营地。2026 年 11 月 2 日开发。

## 新玩法

原岛建造远征手记台，接受九项可选委托，走进三片远征地图的十八处探索点。古井可选择铜锭工程修复或种子生态修复；种荚、林穴、倒伏巨木、旧匣和回声石碑提供不同的材料与回报。每处奖励只能领取一次，移动、攻击与受伤会中断探索，完成时才扣材料。可用诱饵创造观察时间，无需击杀区域野怪也能完成全部林海委托。

带回构件选择旅行晾晒架或林海育苗床。块根、谷物、荧光花各有偏好的季节，行粮、谷物饼、热饮和炖汤支撑下一趟远征。作物离开地图暂停生长，不通过往返刷收成。附近储物箱可为合成、建造与烹饪供料；限当前地图 180 步内的普通材料，先背包后箱子。

弓可选稳准/连射，锤可选打断/集中破甲，选择与切换均消耗构件。林猪和蜘蛛保卫近处领地，霜狼互相警戒；诱饵吸引普通野怪，守卫仍保持威胁。

新旅程可选「探索」或「求生」。探索模式死亡后可回原岛营火，保留装备和食物，半数普通材料留在原地图遗落包中供找回。没有原岛营火不能直接复活；求生模式保留死亡后重新出发的压力。

## 粉丝反馈修复

播种不需要共生科技：从合成的营地/生存分类、背包种子、7 号快捷栏进入选点，支持连续播种和身边空地寻找。科技页显示三次播种与前置研究进度。顶部共鸣、生态按钮打开可操作的成长指引，说明荧光花冥想、补植与树苗成长奖励的区别。

二级科技页不再显示已完成的一级晋升清单。开始页与菜单明确目前是单人网页版，联机与微信小游戏仍为后续独立里程碑。

## 存档与隐私

新版使用 v6 槽位，自动迁移 v5/v4/v3/v2。原槽位保留，更新前仍建议导出备份。旧旅程默认求生，新难度在新旅程开始前选择。匿名统计维持默认关闭，沿用原有字段与独立数据，不上传存档、物资或私信。
