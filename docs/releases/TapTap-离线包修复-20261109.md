# TapTap 离线包修复（2026-11-09）

本次核对的目标是开发者 521402 /《九级》1027402。平台确认 V-20261106（主键 1220639、H5 版本 440182）审核失败，原因是检测到联网功能并要求办理小游戏 ICP 核准。V-20261104 仍为已上线版本。隐私、AI 声明、16+ 适龄资质仍有效批准；这些批准不能代替 ICP 核准或本次整版审核。

## 发现与修复

旧 TapTap 构建只将统计开关设为关闭，仍带入 `fetch`、统计服务地址、菜单官网/GitHub 外链以及网页版隐私文案。静态检查在 1.3.2、2.0.0、3.0.0 的旧候选中均找到了这些内容。这与退审描述吻合，但平台没有提供逐项检测报告，不能断言外链或某一处函数就是唯一触发原因。

新版打包流程直接排除联网统计实现，移除统计选择、定时器及外链，使用离线版隐私说明，并加入 `connect-src 'none'` 内容策略。网页版仍保留原有的可选匿名统计和官网入口。所有游戏资源、存档、导入导出仍在本地工作。

构建后会扫描实际交付的 JS、HTML、CSS、SVG，检测已知联网接口、外部地址及导航能力，发现残留则终止打包。SVG 命名空间不是资源请求，单独识别。该扫描与浏览器断网验证是开发侧证据，不是平台合规批准。

新增 5 项回归测试覆盖：关闭开关但残留请求、相对地址请求、外链和远程图片、入口漂移、离线适配及隐私策略。全部 134 项规则测试与语法检查通过。
