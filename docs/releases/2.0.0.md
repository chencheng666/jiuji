## 六片地图与文明课题

新增镜沙遗境、星环残骸，与原岛、苔痕林海、烬岩荒原、霜月冻土组成六张独立地图。每张地图保存自己的资源、建筑、迷雾与野怪，拥有一处可操作遗构和一段营地约定。

连锁灯、有限功率配电、镜面反射和信号记忆均需观察后操作；错误不扣材料，正确奖励仅发一次。两名新守卫各有三阶段行为，光束、冲锋、砸地与环形攻击有对应安全区域；可以选择战斗，也可以修复其核心，取得同等主线资格。新增四类普通生物、两名守卫和弧光刃、棱镜长弓、引力锤。

## 工业与资源守恒

- 风能塔持续供能，星光集能板昼夜产能不同；同图工业共享晶能，设备有低、常规、高三档优先级。
- 装配台先装入真实材料，再设置木板、铜锭、合金、棱镜、口粮或晶能电池配方，达到库存目标后等待。
- 货栈实际装载并扣除晶能，15 秒运输后入目的地库存。停用路线仍会送达在途货物，读档不复制；满仓时等待，不能拆除仍有在途货物的站点。
- 接入货栈的地图在远行期间继续供能与工业运转；普通农圃、旧经营订单仍按旧规则暂停。游戏暂停、切到后台与离线均不推进生产或物流。
- 投影臂只协助采集身边普通资源，仍消耗工具耐久与便携晶能，并积累热量。过热会安全收臂，可散热后再次展开。
- 工业失衡可通过关闭设备、共鸣调谐与生态花园修复，过载保护可以恢复，不永久锁死存档。

## 操作与手机界面

N 打开文明控制台，P 展开或收起六级投影臂；原有采集、合成、科技、背包、地图和经营入口保留。营地菜单支持收起、展开和记住偏好，关闭按钮使用居中的 SVG。新面板支持窄屏、横屏滚动和触控操作，系统减少动态效果设置会减少投影与传送装饰。

开局可选世界种子、经典或星海旅程、探索或求生难度。同种子生成相同资源分布。存档升级至 v8，兼容 v2—v7，迁移保留进度；请在更新前导出备份。
