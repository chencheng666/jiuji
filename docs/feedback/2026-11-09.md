# 2026-11-09 公众号反馈与手机收尾

来源：已登录 Ego Lite 公众号「数字机器莱西奥」私信搜索、11 月 6 日《九级》2.0 文章留言及回复，以及用户直接提供的两张反馈截图。仅保存匿名问题摘要，不公开聊天头像、昵称、账号信息或后台登录链接。读取不代表已回复、精选或删除。

| 反馈 | 处理 |
| --- | --- |
| 手机荒野手记挡视野，想放在角落的小地图 | 手机手记默认收起、按需展开，右上角小地图可直接打开大地图；手记和营地菜单互斥展开，避免两个面板叠在一起 |
| 移动操作不明显 | 操作设置明确说明摇杆、左右手、动作键与物品横向滑动；实际触摸验证摇杆移动与点击 |
| 种一棵就要重新进菜单 | 从种子快捷栏或背包拿出后默认连续播种，种完或主动取消时收起；取消与无效落点不扣种子 |
| 不知道怎样升二级、下一级差什么 | 常驻成长提示；完整条件包含原有科技、设施、生态、意识与共鸣及新增主线目标；定位或建造晋升设施 |
| 副本进不去、地图小 | 地图说明常驻虫洞等级与两类裂隙出发条件，并提供远征入口；保留六张常驻地图和两类可重复裂隙 |
| 想研究并修改开源代码 | 文章保留 GitHub 地址，欢迎在开源项目中提问题、改代码，不把“可自行修改”当作拒绝修复用户反馈的理由 |
