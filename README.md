# 九级 · 裂隙远征

原创俯视角单人生存游戏。采集、合成、建造、四季生活与双轨科技，从一根树枝成长到九级文明。

## 1.1 裂隙远征

- 原岛 + 苔痕林海、烬岩荒原、霜月冻土，四张独立地图，总探索面积为原版四倍。
- 免费往返虫洞，地图分别保存资源、营地、迷雾和野怪。离开地图暂停生产与刷新计时。
- 六类普通野怪、三名区域守卫，冲锋、远程吐丝、范围砸地都有可躲避预警。
- 林语弓、箭矢、碎岩锤、霜晶长矛、余烬法杖与蛛丝绷带；弱点克制、装备切换、消耗品和修理。
- V 闪避与野怪/武器图鉴，三项远征手册目标。新增探索为可选内容，不阻断原有主线。
- 保留四季、温度、钓鱼、鱼汤、雨天湿度、诱捕、炖煮和生态恢复。
- 保留一级至九级完整主线、六处遗迹与两种结局，支持旧版存档迁移。
- 匿名统计默认关闭；明确同意后才统计有效游玩时长、地图、等级和设备。存档留在本机。
- 桌面封装和统信 DEB 构建流程。构建、商店提交与目标系统真机验收是不同状态，以发行记录为准。

## 运行

浏览器版使用 Node.js 18+，游戏运行不依赖第三方包：

```sh
npm run dev
```

打开终端中的本机地址；部署整个 `dist/`。不要直接双击 HTML。手机可以使用触屏按钮，微信小游戏、小程序与联机仍是后续计划。

桌面包构建需要 Rust、Tauri 和对应系统依赖：

```sh
npm ci
npm run desktop:build
```

## 操作

WASD / 方向键移动，点击资源自动走近采集，E 交互，空格攻击，V 闪避。C 合成、T 科技、B 背包、M 地图、H 图鉴、J 历程、F 添柴。Q 闪步和 R 归途随等级解锁。

先拾取树枝与燧石，制作石斧、石镐；天黑前建立营火，准备食物和火炬。远征前制作弓箭，在背包点击武器装备。虫洞入口是安全落脚区，回程不消耗材料。打开面板与离开页面会暂停游戏，定期导出存档备份。

## 验证与共建

```sh
npm test
npm run check
npm run test:journey
npm run test:wilderness
npm run test:expedition
```

规则、地图和战斗分别位于 `survival.js`、`expeditions.js`；四季和手册在 `seasons.js`，Canvas 画面在 `world.js`、`expedition-view.js`，界面在 `play.js`。素材为原创 SVG。

自动流程不等同于所有设备的人工全程体验。欢迎在 Issue 提供设备、游戏版本、复现过程和截图。MIT 许可证，参见 [共建指南](CONTRIBUTING.md)。
