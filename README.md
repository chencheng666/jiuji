## 保留 3.2 荒野邻居

- 原野鸡、棉尾兔、栗鼠、晨露蝶、雨铃蛙、星点萤、落叶刺团和迁徙花鹿按昼夜、季节、雨后或换季出现。安静走近可观察，每种仅首次获得洞见；动物手记说明出现时段。
- 研究「万物观察 → 温和驯养」，建鸡舍、兔苑，消耗种子或浆果引领动物沿通路回营地。投料后取得鸡蛋、自然脱落兔绒和少量堆肥，再制作营火煎蛋与保暖披肩。
- 遮雨棚扩容、真实口粮繁育；三级研究机械助手并完成工坊共同事务后，可安装消耗储备饲料与晶能的自动喂料器。缺粮只等待，暂停、离线与离开原岛不产出。
- 走近聚落进入公共火屋、协作工坊、种子屋，使用摇杆、WASD 或点地面穿过房门。物资交付与休息都需要靠近居民；内部探索时室外生产暂停，离开返回原位置。
- 夜色与实际光照保护范围对齐，简化渲染也保留光圈；查看生存准备可了解火炬、营火续航。原岛远处有领地性林猪，沿用冲锋预警与避战机制。
- 手机横竖屏对话独立滚动，照料次要功能折叠；摇杆与页面长按不选字，真实输入框保留文字编辑。
- [本地验收说明](docs/releases/v3.2.0/README.md)。使用 `npm run test:countryside` 从一级正常采集走完养殖、烹饪、工坊和自动喂料流程。

## 保留 3.1 营地助手

- 首次进入直接开始，死亡规则、地图种子和旧版成长规则按需展开；重新开局保留上一段旅程，可以预览恢复。
- 饱食 40/20 分级提示，提前准备雨夜、柴火、寒暑和下一季；预测标注活动假设，不额外扣能力。
- 二级研究机械助手，真实扣料组装拾荒机。独立采集树枝、燧石、纤维和浆果，按范围与库存目标停工，自动卸货、充电、遇险返回。
- 聚落居民按昼夜、天气和附近危险自主行动；原有公共储备仍负责人口与生产，不用动画凭空增加物资。
- 新手建议按当前进度最多显示三条；手机详细管理按需打开，旧存档兼容。
- `npm run package:desktop-web` 生成可直接用浏览器打开的离线 ZIP，以及供 Tauri 安装包使用的离线资源。Windows/macOS 构建工作流不自动上架商店。

## 运行

浏览器版使用 Node.js 18+，游戏运行不依赖第三方包：

```sh
npm run dev
```

打开终端中的本机地址；部署整个 `dist/`。不要直接双击 HTML。手机可以使用虚拟摇杆和触屏按钮，微信小游戏、小程序与联机仍是后续计划。

桌面包构建需要 Rust、Tauri 和对应系统依赖：

```sh
npm ci
npm run desktop:build
```

### uTools 离线版

应用名称为「饥荒升级版-九级」，指令包含「九级」「九级生存」。1.3.1 于 2026 年 11 月 3 日提交市场，后续审核状态以平台回读为准；可从 [GitHub 下载正式 UPXS 安装包](https://github.com/chencheng666/jiuji/releases/tag/utools-v1.3.1)。应用内注明原创项目与玩法灵感来源，并非《饥荒》官方版本。

```sh
npm ci
npm run package:utools
```

在 uTools 开发者工具中导入 `releases/utools-v3.0.0/饥荒升级版-九级/plugin.json`。构建时将游戏模块和样式合并为本地文件，关闭匿名统计，保留本地素材、独立游戏窗口与存档导入导出。网页版与 uTools 存档不自动同步，迁移或更新前请手动备份。外部试玩、官网与 GitHub 仅在点击入口按钮后打开。

目录 ZIP 用于开发导入与备份，正式 `.upxs` 必须由 uTools 开发者工具生成。打包与送审状态见 [uTools 发行记录](docs/releases/utools-20261102/README.md)。

## 操作

WASD / 方向键移动，点击资源自动走近采集，E 交互，空格攻击，V 闪避。C 合成、T 科技、B 背包、M 地图、H 图鉴、J 历程、L 远征委托、F 添柴。N 文明控制台，P 投影臂（六级）。Q 闪步和 R 归途随等级解锁。

先拾取树枝与燧石，制作石斧、石镐；天黑前建立营火，准备食物和火炬。远征前制作弓箭，在背包点击武器装备。虫洞入口是安全落脚区，回程不消耗材料。打开面板与离开页面会暂停游戏，定期导出存档备份。

```sh
npm test
```

规则、地图和战斗分别位于 `survival.js`、`expeditions.js`；四季和手册在 `seasons.js`，Canvas 画面在 `world.js`、`expedition-view.js`，界面在 `play.js`。文明课题与工业逻辑在 `odyssey-data.js`、`odyssey.js`，界面和动作渲染在 `odyssey-ui.js`、`odyssey-view.js`。3.0 配置、规则、界面和画面分别在 `symbiosis-data.js`、`symbiosis.js`、`symbiosis-ui.js`、`symbiosis-view.js`；设备控制在 `device-controls.js`。场景素材为原创 SVG，品牌图标为原创生成图片。

自动流程不等同于所有设备的人工全程体验。欢迎在 Issue 提供设备、游戏版本、复现过程和截图。MIT 许可证，参见 [共建指南](CONTRIBUTING.md)。
