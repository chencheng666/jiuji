## 1.0 四季营地

- 完整一级至九级主线，六处遗迹，两种结局，结局后继续生存。
- 36 项合成配方、19 类设施、20 项双轨科技。
- 四季每季四天。披肩、火炬、营火保暖，庇护所遮阳避雨；极端体感额外消耗饱食与意识。
- 三处鱼塘、枝编钓竿、溪鱼和暖身鱼汤；钓鱼可中断、消耗耐久，鱼群定时恢复。
- 八项生存手册目标与一次性奖励，覆盖工具、营地、钓鱼、烹饪与成长。
- 雨天湿度、诱捕野兔、毛皮披肩、营地炖煮、循环农圃与生态恢复。
- 自动存档、上一份备份恢复、JSON 导入导出，兼容 0.2 / 0.3 / 0.4 生存存档。
- 手机触控、窄屏布局与安全区域；移动端经过浏览器尺寸模拟，欢迎真机反馈。

当前为单人、单岛屿游戏。微信小游戏、小程序、联机和多星球属于后续计划，尚未实现。存档在本地浏览器，不能跨域自动同步，请定期导出。

## 启动

需要 Node.js 18 或以上，无第三方依赖。

```sh
npm run dev
```

浏览器打开终端显示的地址。静态托管发布整个 `dist/`，不要双击 HTML。

## 开始生存

1. 拾取树枝、燧石，制作石斧与石镐。
2. 采木、采石，天黑前搭营火和庇护所。
3. 食用浆果或烹饪食物，添柴，制作火炬远行。
4. 建研究台，研究石器精研与万物观察；冥想、播种，平衡物质与意识。
5. 打开「历程」查看晋升与遗迹目标；打开「手册」查看季节与领取奖励。

WASD / 方向键移动，点击资源自动走近采集，E 交互，空格攻击，F 添柴。C 合成、T 科技、B 背包、M 地图、J 历程。Q 闪步、R 归途按阶段解锁。手机可用方向键、点击移动与采集按钮。打开面板和离开页面时世界暂停。

## 开发与验证

规则位于 `dist/survival.js`；高阶成长位于 `chapters.js`；荒野生活位于 `wilderness.js`；四季与手册位于 `seasons.js`；存档恢复位于 `storage.js`；Canvas 渲染和界面位于 `world.js`、`play.js`。素材为原创 SVG。

```sh
npm run check
npm test
npm run test:journey
npm run test:wilderness
```
