# 九级 · 从荒野到星海

原创俯视角生存网页游戏，当前版本 **0.4.1**。从空手采集开始，制作工具、建造营地、研究物质与意识科技，探索六处遗迹，逐级成长到九级。当前已贯通一级至九级的单人主线，是可以继续扩展的生存原型。

国内在线试玩：<https://www.daguojueqi.site/jiuji/>，与《大国崛起》部署在同一台腾讯云上海服务器。

从原 Sites 地址迁移时，请先在旧地址的菜单中导出存档，再到新地址导入；浏览器不会跨域自动搬迁本地存档。部署方式与实际验收见 `docs/tencent-deployment.md`。

## 启动

需要 Node.js 18 或以上，无第三方依赖，无须安装包。

```sh
npm run dev
```

打开终端显示的 `http://127.0.0.1:4317/`。静态托管时将 `dist/` 整个目录发布即可。由于使用原生模块，请通过 HTTP 服务打开，不要直接双击 HTML。

## 前五分钟

1. 点击身边的枯枝、燧石，角色会自动走近采集。打开合成栏，制作石斧与石镐。
2. 砍两棵树，开采岩石，收集纤维；在营地配方中选择营火，在空地放置。
3. 采集浆果。靠近燃烧的营火可以烤浆果，点击快捷栏或背包中的食物即可食用。
4. 建研究台，在附近研究「石器精研」与「万物观察」。首次发现资源、探索区域、制作物品与调查遗迹都能积累洞见。
5. 天黑前准备火炬，或回到营火旁添柴。学会万物观察后，可消耗荧光花冥想获得共鸣；黄昏或夜间可用睡袋休息到清晨。

## 0.4 荒野生活

- 墨线风格地表与旧路、较大的旅人和青杉、砍伐动作、倒树扬屑、兔洞野兔、营火暖光和炊烟；新增 12 张原创 SVG。
- 合成侧栏可追踪材料；普通消耗品支持一次制作 5 份。建筑提供网格、有效范围、阻挡原因和连续放置。
- 第二天开始每两天一场 90 秒阵雨，提前 30 秒提示。淋湿影响意识，靠近庇护所或营火可晾干；雨天消耗更多燃料。
- 兔洞附近建诱捕笼，投入 1 浆果，60 秒后领取 2 生肉和 1 毛皮。3 毛皮加 6 纤维可做披肩，自动穿戴，淋湿速度降低 75%。
- 采集可再生菌菇，研究石器精研后建烹饪锅。菌菇汤和炖肉需要 12 秒，成品留在锅中待领取；打开面板或离开页面时计时暂停。
- 采集与操作音效由浏览器生成，可用右侧开关静音。旧版 0.2 / 0.3 存档会接续，原物品和营地保留。

## 操作

| 操作 | 键盘 / 鼠标 |
| --- | --- |
| 移动 | WASD / 方向键，或点击地面 |
| 奔跑 | Shift + 移动 |
| 采集 / 使用设施 | E；点击资源可连续采集 |
| 攻击附近夜影 | 空格 |
| 给附近营火添柴 | F，或交互提示中的添柴按钮 |
| 建造网格 / 连续建造 | G；按住 Shift 连续放置，手机可用屏幕开关 |
| 合成 / 科技 / 背包 / 地图 | C / T / B / M |
| 九级历程 | J，查看阶段目标与遗迹坐标 |
| 闪步 | Q，三级解锁，消耗 4 意识 |
| 归途 | R，四级建成折跃门后解锁，消耗 2 共鸣 |
| 快捷物品 | 1–8，或点击物品 |
| 暂停 / 关闭面板 / 取消放置 | Esc |

手机支持点击移动、点击资源采集、屏幕方向键、采集/攻击和高阶能力按钮。打开面板与切到后台时世界暂停，关闭页面后不会离线消耗资源。遗迹调谐会返回世界并消耗实际游戏时间，移动或主动攻击会中断，完成时才扣除材料。

## 已实现

- 一座固定种子的岛屿，五类区域、探索迷雾、地图和营地标记。
- 角色移动与点击寻路、采集节点、工具耐久、战斗和夜影。
- 昼夜循环、生命/饱食/意识、光源安全区、烹饪、睡眠、冥想。
- 35 个合成配方、2 个炖菜配方、19 类设施，包含营火、熔炉、农圃、采矿机、观星仪、折跃门、自动合成站、塑能台、共生花园与归一星环。
- 20 项双轨科技。生态通过采伐消耗、播种与农圃恢复；高阶晋升同时检查科技、遗迹、生态、意识和共鸣。
- 一级晋升需完成两条科技路线、度过夜晚、维持生态/意识并储备共鸣。
- 二级开放星陨高地、自动采矿与持续照明；点亮信标后进入三级。
- 六处独立遗迹：潮汐回声、破碎坐标、受伤的林地、静默矿脉、沉睡聚落、最后的来访者，包含种植修复、材料取舍与持续调谐。
- 高阶能力逐步改变玩法：闪步、营地传送、自动生产、意念显化、生态恢复、自身照明，九级不再消耗饱食。
- 九级可选择「留下守护」或「归还星海」，结局后保留营地并继续自由生存。
- 储物箱存取、设施拆除回收、研究台旁修理装备、草药膏与藤编护甲。
- 自动存档、JSON 导入导出、重新开始确认、键盘与手机操作。
- 全部世界资源、角色与设施为本项目原创 SVG，运行不依赖外部字体或图片服务。

目前仍是单人、单岛屿原型。联机、多星球地图、复杂季节系统、更多野生生物与长线生态模拟尚未制作；九级主线、素材与生存平衡可继续迭代。

## 九级进程

| 等级 | 核心目标与能力 |
| --- | --- |
| 一级 · 初醒 | 采集合成、建立营地、平衡双轨科技与生态 |
| 二级 · 协同 | 探索星陨高地，建造采矿机并点亮信标 |
| 三级 · 觉醒 | 开采陨星矿、学习闪步、完成潮汐试炼 |
| 四级 · 远航 | 建立折跃门、找回破碎坐标、解锁归途 |
| 五级 · 同频 | 自动合成资源，修复受伤的林地 |
| 六级 · 塑能 | 意念显化材料，稳定静默矿脉 |
| 七级 · 守序 | 在三个不同区域建立花园，帮助沉睡聚落 |
| 八级 · 信使 | 自身持续照明，记录六处遗迹，建造归一星环 |
| 九级 · 归一 | 完成最后的选择，继续守护或归还星海 |

## 开发结构

- `dist/survival.js`：纯游戏状态与规则。
- `dist/chapters.js`：三级至九级的科技、配方、试炼与阶段配置。
- `dist/wilderness.js`：天气、湿度、诱捕与炖煮规则。
- `dist/atmosphere.js`：地表、采集动作、天气与建造预览。
- `dist/audio.js`：浏览器合成音效与静音控制。
- `dist/world.js`：Canvas 地形、角色、光照与地图渲染。
- `dist/play.js`：交互界面、键盘/触控、存档和主循环。
- `dist/survival.css`：桌面与移动端布局。
- `dist/assets/`：原创 SVG 素材；`assets-preview.html` 为素材联系图。
- `tests/survival.test.mjs`：规则回归测试。
- `tests/chapters.test.mjs`：高阶能力、储物、迁移、晋升与结局回归测试。
- `tests/nine-level-journey.mjs`：全程使用公开操作、无资源或科技注入的一级至九级通关验证。
- `archive/council-v0.1/`：先前文明议会版本，仅作历史保留；对应 Git 标签 `prototype-council-v0.1`。

```sh
npm run check
npm test
npm run test:journey
npm run test:wilderness
```

存档保存在浏览器本地。正式进度使用 `jiuji.survival.v4`；开发验收可用 `?slot=名称` 隔离存档。首次更新时依次读取旧的 `jiuji.survival.v3` 与 `jiuji.survival.v2`，也可以导入旧版 JSON：已点亮信标的存档从三级继续，其余保留原等级；物品、营地与原存档均保留。导入失败不会替换当前进度。旧议会版本存档不兼容生存版本。

本轮验证见 `docs/verification-v0.4.md`；0.3 历史验收保留在 `docs/verification.md`。
